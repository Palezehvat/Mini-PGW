# Mini-PGW
Проект, являющийся упрощённой моделью сетевого компонента PGW (Packet Gateway), способный обрабатывать UDP-запросы, управлять сессиями абонентов по IMSI, вести CDR-журнал, предоставлять HTTP API, поддерживать чёрный список IMSI и корректно завершать работу.

## Версия
Текущая версия: **1.0.0**

## Установка зависимостей
```
sudo apt update
sudo apt-get install build-essential
sudo apt-get install cmake
sudo apt-get install git
```

## Запуск приложения
### Запуск сервера

#### Сборка проекта и запуск сервера из директории `build`:

```
mkdir build
cd build
cmake .. && make
```

**Конфигурация сервера:**

| Название                   | Тип                           | Значение                                                                                     | Пример
|----------------------------|-------------------------------|----------------------------------------------------------------------------------------------|---------------|
| `"type"`                   | Строка                        | `"server"`                                                                                   | `"server"`              |
| `"udp_ip"`                 | Строка                        | IP  сервера                                                                                  | `"0.0.0.0"`             |
| `"udp_port"`               | Неотрицательное целое число   | UDP Порт сервера                                                                             | `9000`                  |
| `"session_timeout_sec"`    | Неотрицательное целое число   | Количество секунд через сколько истекает сессия                                              | `10`                    |
| `"cdr_file"`               | Строка                        | Путь относительно корня проекта для CDR                                                      | `examples/server/cdr1.log`                |
| `"http_port"`              | Неотрицательное целое число   | HTTP Порт сервера                                                                            | `8080`                  |
| `"graceful_shutdown_rate"` | Неотрицательное целое число   | Количество сессий удаляемых подряд(далее задержка в секунду) при выключении сервера          | `5`                     |
| `"blacklist"`              | Список строк                  | IMSI, которые входят в чёрный список                                                         | `["001010123456789", "001010000000001"]` |

#### Основная команда:
```
./server/servermain <path_to_log_file> <path_to_config> [clear_logs]
```

**Параметры запуска сервера:**

| Параметр             | Обязательность | Описание                                              |
|----------------------|----------------|-------------------------------------------------------|
| `<path_to_log_file>` | Обязательный   | Путь к файлу для логов                                |
| `<path_to_config>`   | Обязательный   | Путь к конфигурационному файлу                        |
| `clear_logs`         | Опциональный   | Если указан, лог-файл будет очищен перед запуском     |

#### Пример запуска:
```
mkdir build
cd build
cmake .. && make
./server/servermain ../examples/server/logs1.txt ../examples/server/configs/config1.json clear_logs
```
#### Работа с HTTP сервером

Сервер предоставляет два метода для работы с ним

Получение информации о наличии сессии для определённого IMSI:

| Назначение            |   Метод  |       Эндпоинт      |    Параметры    |            Ответ          |
|-----------------------|----------|---------------------|-----------------|---------------------------|
| **Проверка сессии**   | **GET**  | `/check_subscriber` | `imsi = <IMSI>` | `active` или `not active` |
| **Остановка сервера** | **POST** |       `/stop`       |       Нет       |        `stopping`         |

#### Пример работы с HTTP сервером
```
curl "http://127.0.0.1:8080/check_subscriber?imsi=123456789012345"
```
Остановка сервера:
```
curl -X POST -d "" http://127.0.0.1:8080/stop 
```

### Запуск клиента
#### Сборка проекта и запуск клиента из директории `build`:

```
mkdir build
cd build
cmake .. && make
```

**Конфигурация клиента:**

| Название             | Тип                           | Значение     | Пример
|----------------------|-------------------------------|--------------|-------------------------|
| `"type"`             | Строка                        | `"client"`   | `"client"`              |
| `"server_ip"`        | Строка                        | IP  сервера  | `"127.0.0.1"`           |
| `"server_port"`      | Неотрицательное целое число   | Порт сервера | `9000`                  |

#### Основная команда:
```
./client/clientmain <path_to_log_file> <path_to_config> <imsi> [clear_logs]
```

**Параметры запуска клиента:**

| Параметр             | Обязательность | Описание                                              |
|----------------------|----------------|-------------------------------------------------------|
| `<path_to_log_file>` | Обязательный   | Путь к файлу для логов                                |
| `<path_to_config>`   | Обязательный   | Путь к конфигурационному файлу                        |
| `<imsi>`             | Обязательный   | IMSI в формате строки ASCII                           |
| `clear_logs`         | Опциональный   | Если указан, лог-файл будет очищен перед запуском     |

#### Пример запуска:
```
mkdir build
cd build
cmake .. && make
./client/clientmain ../examples/client/logs1.txt ../examples/client/configs/config1.json 001010123456788
```
